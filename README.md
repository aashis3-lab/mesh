# mesh.

One-screen landing page for Mesh, an NFC profile card for students.

```bash
npm install
npm run dev
```

**Before launch:** set `formEndpoint` (and `contactEmail`) in `site.config.ts`.
Create a form at formspree.io and paste its `https://formspree.io/f/...` URL.

**Deploy:** push to GitHub and import the repo in Vercel. No settings needed.
